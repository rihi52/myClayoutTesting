# Guidnbatter

A grapical version of [clidnbatter](https://github.com/rihi52/clidnbatter) using [Clay](https://github.com/nicbarker/clay) and SDL3.

![image](https://github.com/rihi52/myClayoutTesting/blob/main/assets/home.png)

The goal is it have a graphical version of clidnbatter, with a bit more functionality.
Currently I have a searcheable sqlite database of all 5th edition SRD creatures.

![image](https://github.com/rihi52/myClayoutTesting/blob/main/assets/dbsearch.png)

Build and save encounters ahead of time during prep, or on the fly.

![image](https://github.com/rihi52/myClayoutTesting/blob/main/assets/build.png)
![image](https://github.com/rihi52/myClayoutTesting/blob/main/assets/SavedEncounter.png)

There is a combat tracker that keeps AC's, stat blocks, and hitpoints in front of you. Use the space bar to cycle turns (the red outline is the current turn) and modify the number of creatures and initiative order with the Add to Initiative button.

![image](https://github.com/rihi52/myClayoutTesting/blob/main/assets/RunningCombat.png)
